# valresultat

`valresultat` är ett R-paket för att hämta, arkivera och bearbeta svenska
valdata från Valmyndigheten. Målet är att göra valdata lättare att använda
i forskning och andra analyser, med tydliga tabeller och bevarad källinformation.

Utvecklingen fokuserar för närvarande på **valet 2026** till riksdag,
regionfullmäktige och kommunfullmäktige. Stöd för historiska val planeras senare.

Paketet avser att tillhandahålla:

- preliminära och slutliga valresultat samt valdeltagande på olika geografiska nivåer,
- mandatfördelning,
- kandidaturer, kandidater, valda ledamöter och ersättarrelationer,
- list- och personröster samt kopplingar mellan nuvarande och tidigare valdistrikt.

Rådata kan läsas direkt från Valmyndigheten eller från ett lokalt rådataarkiv.
Det finns stöd för uppdatering av arbetskopior och daterad arkivering för
reproducerbara analyser. Rådata förvaras separat från paketets källkod.

**Paketet är under aktiv utveckling.** Alla planerade delar är ännu inte
färdiga, och funktioner och dokumentation kan förändras. Genreps- och testdata
för 2026 kan förekomma under utvecklingen.
